VidSearch is a lightweight multimodal video understanding and retrieval engine.

[overview]
VidSearch is a lightweight multimodal video understanding and retrieval engine.
It extracts key frames from video clips using ffmpeg, computes dense vector embeddings, builds a fast Faiss vector index.
It provides Frame Extraction: vidsearch.frames samples video keyframes with ffmpeg.

[diagram]
vidsearch/cli dot py is the command-line interface for VidSearch video retrieval engine.
It connects to vidsearch/search dot py, which query vector index and rank matching video segments.

[code]
In vidsearch/cli dot py, main run CLI search execution.
Inside main, it invokes parse args and search video index.

[terminal]
Run pip install -r requirements dot txt to install.
Next, execute the quickstart command to run the tool.
