VidSearch is a lightweight multimodal video understanding and retrieval engine.
It extracts key frames from video clips using ffmpeg, computes dense vector embeddings, builds a fast Faiss vector index.
vidsearch/cli dot py is the command-line interface for VidSearch video retrieval engine.
In vidsearch/cli dot py, main runs CLI search execution.
Run pip install -r requirements dot txt to install dependencies for vidsearch py.
Next, execute the quickstart command shown on screen.
vidsearch py handles the decode, embed, index and query steps of a video retrieval pipeline.
To dive in, open vidsearch/cli dot py.
