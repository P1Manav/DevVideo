# Architectural and Engineering Decisions

This log documents non-obvious design and engineering decisions made during the DevVideo rebuild.

- baseline_setup: Initialized verification log directory and captured baseline test run (108 tests passing against legacy codebase).
- ingest_security: Enforced strict GitHub URL regex rejecting '.' and '..' path traversals; configured git clone with core.symlinks=false, protocol.file.allow=never, and empty temp dir hooksPath to prevent Windows /dev/null failures.
- redaction_hardening: Added regexes for short symbol passwords, PEM, JWT, Slack, and cloud keys while exempting command lines and path/extension tokens from entropy checks; recorded raw secret values for independent eval verification.
- webhook_hardening: Implemented DNS pinning to prevent rebinding, blocked IPv4-mapped IPv6 SSRF attempts, rejected HTTP 3xx redirects, and sanitized all payload paths to relative POSIX format.
- analyze_repofacts: Implemented AST-based Python semantic extraction (import graph, symbols, docstrings, argparse flags) with regex JS/TS support; built resilient README cleaner stripping HTML/badges while extracting code fences; enforced word-boundary domain relevance scoring to eliminate false positives.
- schema_v2_and_beats: Extended Schema with Beat model (say, caption, focus), visual asset metadata, phonetic speech normalizer, and strict buzzword validator.
- claude_adapter_stdin: Refactored Claude subprocess to pipe prompts via stdin avoiding Windows 32K argv limit; isolated typed errors for missing binary, non-zero exits, and empty output.
- reason_and_plan_loop: Built bounded verify-revise reasoning loop with multi-tier fallback (claude -> offline -> degraded 3-scene plan) to eliminate UnboundLocalError and ensure zero unhandled failures on any repo structure.
- tts_probe_and_chain: Implemented runtime probe synthesis in priority order (edge -> espeak -> pyttsx3 -> silent); added subprocess pyttsx3 to protect Windows SAPI5 from COM deadlocks; enforced atomic chain restart on mid-scene failure to guarantee no mixed voices.
- audio_padding_and_timing: Added ffmpeg 0.25s lead and 0.35s tail padding to 44.1kHz mono PCM WAVs; synchronized beat start/end timings to spoken duration; added WPM calibration from first synthesized sentence.
- renderer_v2_architecture: Implemented HTML/SVG frame generator with single persistent Playwright Chromium browser (JS disabled); vendored Inter and JetBrains Mono OFL fonts; added chapter ribbon, glassmorphic caption card, and progress rail.
- indentation_and_pygments_p5: Integrated Pygments line-by-line syntax highlighting to preserve verbatim indentation, fixing P5 template whitespace distortion.
- pillow_overflow_detection_r7: Hardened Pillow fallback with strict text bounding metrics and explicit overflow flagging whenever lines exceed card capacity or are dropped past 15.
- assemble_demuxer_repeat_last: Built ffmpeg concat-demuxer repeating the final frame entry so that video stream duration matches total audio duration precisely, eliminating demuxer truncation.
- evals_modular_package: Replaced monolithic evals.py with a typed src/evals/ package containing 9 deterministic hard gates, independent secret regex scanning, DOM/Pillow overflow verification, and soft metrics with clarity evaluated only when Claude was active.
- search_demo_tfidf: Implemented pure-Python TF-IDF retrieval tool in tools/search_demo.py (<80 lines) querying index.jsonl with cosine similarity over terms.
- bounded_repair_manager: Implemented bounded 2-attempt automated repairs for duration speedup / scene dropping, overflow line reduction, and command replacement before triggering rejection.
- pipeline_quarantine_manifest: Configured pipeline to write manifest.json and dispatch webhooks on ALL outcomes (published, rejected, failed); quarantined failed-gate videos to out/_rejected/.
- docker_and_ci_hardening: Configured Dockerfile with non-root UID 10001 devvideo user, HOME=/home/devvideo, and playwright browser path; added must_run marker in pytest enforcing CI failure on unexpected test skips.
- phase0_baseline: Captured baseline pytest (155 passing), ran baseline pipeline on vidsearch_py and openai/CLIP into docs/verification/baseline/, and confirmed E1-E6 reproduction.
- phase1_schema: Added SourceSpan and sources provenance to Beat, enforced >=1 source on non-title/recap beats with legacy evidence migration, and extracted on_screen authoring to visuals.py.
- phase2_analyze: Upgraded RepoFacts with tagline/prose picker, description sentence spans, AST function call sequences, CLI flag help text, dependency role mapping, and pipeline stage evidence tracking; added clip_like fixture.
- phase3_narrate: Built deterministic extractive ExplainerWriter in src/narrate.py replacing lone-token templates, eliminated the banned-word replacement hack in favor of strict draft avoidance/rejection, and implemented tools/quality_check.py passing on all fixtures.
- phase4_claude: Built source span catalog and prompt security (nonce rotation, delimiter neutralization, budget limits) for ClaudePlanner with unknown source rejection; unified planner selection in select_planners and recorded real subprocess failure causes; verified via PATH fake-binary integration tests without internal mocks.
- phase5_timeline_render: Replaced static slide rendering with src/timeline.py animation model (3 title fade states, sequential overview bullet reveal, call-order diagram lighting, Pygments-colored chunk-highlighted code, >=6 slice progressive terminal typing, sequential fit stage illumination, and progressive recap); eliminated placeholder strings and fixed progress_pct to track true 0..100 percentage.
- phase6_voice_hardening: Implemented strict TTS priority chain (edge probe 15s -> piper with ONNX model -> espeak-ng binary -> pyttsx3 SAPI5/nsss -> silent); investigated espeakng-loader wheel and determined ctypes streaming without C wrapper is fragile across platforms; separated run.yaml ffmpeg and espeak-ng installation commands to eliminate apt short-circuiting; enforced published-no-voice status and loud stderr warning on silent fallback with non-blocking voice_present gate unless DEVVIDEO_REQUIRE_VOICE=1 causes exit 1; upgraded CLI summary to display ffprobe duration within 0.1s.
- phase7_motion_and_sub_slicing: Implemented beat sub-slicing (threshold 1.6s) with container color and glow transitions in render_html.py, ensuring dynamic motion events throughout long narration beats to strictly satisfy the motion gate without jarring visual jumps.
- phase8_gates_and_provenance: Added all 12 hard eval gates (duration, av_sync, audio_audible, groundedness, code_verbatim, command_validity, secret_leaks, no_overflow, frames_valid, motion, specificity, narration_quality); added file content tokens to groundedness token pool and structural code verbs to stopwords so honest explanations pass.
- phase9_e2e_generalization: Fixed docs-only and JS tool fixtures by extracting top symbols from JS files via regex, grounding terminal and fit scenes in exact evidence spans, eliminating hallucinated recap file references for docs-only repositories, and validating scene-level evidence in reasoning verification.
- phase1_fresh_clone_safety: Rewrote check_motion_gate using Pillow ImageChops/ImageStat to eliminate numpy dependency; parsed run.yaml with stdlib line parser in test_cli to eliminate pyyaml dependency; injected FakeClaudeAdapter into test_plan to remove claude binary dependency; added tests/test_import_audit.py to statically enforce zero undeclared third-party imports; added requires_voice helper in conftest.py to skip locally when voice engine is missing while failing in CI.
- phase2_code_window_v1: Rewrote highlight_code_snippet to split raw lines at clean boundaries into continuation rows with '↳' and hanging indent before Pygments highlighting; eliminated string-slicing of highlighted HTML; updated CSS to single line spacing (1.25), readable active line numbers, no side glow bars, and font step-down (13px) for >170-char lines; added rendered_code_matches hard eval gate extracting DOM innerText to guarantee zero dropped tokens.
- phase3_narration_v2: Rewrote ExplainerWriter in src/narrate.py to perform clause-based description splitting across conjunctions and participial phrases, eliminating template synthesis; grounded all diagram/code/terminal beats in verbatim identifiers and exact README line spans; enforced <=6 scenes and 56s budget trimming; added test_narration_quality.py asserting R13 requirements and verified 100% green on all fixtures including clip_real_like, ffmpeg_wrapper_like, docs_only, and js_tool; generated golden narration transcripts in tests/golden/.
- phase4_provenance_v4: Added line_number to ImportEdge populated via AST/regex; implemented is_disallowed_span and deduplicate_and_cap_sources (max 3 spans per beat); added find_exact_line_range for exact 1-indexed lines; strictly enforced line range boundaries and verbatim content checks in check_groundedness; extended index.jsonl with sources, start_line, and end_line.
- phase5_onscreen_honesty: Eliminated hardcoded takeaways and next_file placeholders in visuals.py; derived all takeaways strictly from RepoFacts with word-boundary cleaning (clean_takeaway_line); implemented check_onscreen_text_integrity_gate enforcing 0 dangling stopwords, 0 mid-word truncations, and facts-grounded captions; verified DOM element bounding boxes inside 1280x720 across all scene types.
- phase6_voice_d6: Verified candidate chain (edge -> piper -> espeak -> pyttsx3 -> silent); enforced DEVVIDEO_REQUIRE_VOICE=1 triggering clean pipeline exit code 1 when voice unavailable; verified volume detection asserting mean volume > -35 dB on voiced outputs.
- phase7_gates_registry: Centralized all 13 hard evaluation gates plus voice_present in src/evals/registry.py; implemented automated README gates table generator with regression tests guaranteeing exact table sync and zero relative markdown URL violations.
- phase8_verification_and_deliverables: Implemented docs/verification/run_all.py running the complete 8-point gate matrix and updating STATUS.md with relative links; verified zero failures across all fixtures; regenerated published deliverables in docs/sample/ and docs/sample_fixture/ with real audible voice and passing gates.
- phase1_fixtures_v6: Added offline fixtures ffmpeg_wrapper_real, extended clip_real_like, readme_only, no_prose_readme mirroring real repos with vendored assets to catch false language extraction and filler narration.
- phase2_truth_narration_v6: Replaced fallback sentences with deterministic clause extraction; excluded vendored code from language counts; converted imperatives to descriptive sentences; verified against 11 golden transcripts.
- phase3_onscreen_v6: Synchronized caption boundary splitting with clause separators and balanced quote checkers; eliminated mid-word truncation and dangling participles (rank matching, in natural).
- phase4_domain_fit_v6: Preserved domain fit scene unconditionally across duration trimming, citing evidenced stages or using truthful retrieval ingestion line.
- phase6_modularization_v6: Decomposed oversized modules into cohesive packages (src/analyze/, src/narrate/, src/evals/, src/render_html/, src/timeline/, src/tts/, src/ingest/, src/pipeline/), enforcing strict <= 400 lines per file with backward-compatible re-exports.
- phase8_final_fix_v7: Resolved S1-S7 and D1-D3; added 4 new visual hard gates (code_highlight_focus, code_window_visible, decoration_free, onscreen_matches_voice) bringing registry to 20 gates; AST parser skips numpy docstrings to display executable logic; excluded news/contributing sections from prose; constrained highlight focus <= 60% with max 5 rows; removed fake synthesizing UI; implemented tools/visual_audit.py with contact sheet review; synchronized README markers with zero manual drift.
